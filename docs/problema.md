
# Definición del problema - K.A.T.E.

## 1. Descripción del problema

Actualmente, las personas utilizan diferentes herramientas digitales para organizar sus actividades académicas, personales y laborales. Esto provoca que la información se encuentre dispersa en distintas aplicaciones, dificultando su consulta y administración.

Además, los usuarios deben repetir instrucciones y realizar manualmente tareas que podrían simplificarse mediante un asistente virtual.

## 2. Relevancia del problema

La falta de centralización de información y automatización de tareas puede provocar pérdida de tiempo, desorganización y menor productividad.

Por esta razón, se propone desarrollar K.A.T.E., un asistente virtual personal que permita centralizar información, facilitar consultas y apoyar al usuario en determinadas actividades.

## 3. Objetivo general

Desarrollar un prototipo de asistente virtual personal utilizando Python, capaz de gestionar información, responder consultas y ejecutar determinadas acciones mediante una interfaz sencilla.

## 4. Objetivos específicos

- Implementar algoritmos de búsqueda para recuperar información.
- Diseñar una estructura modular para organizar el proyecto.
- Desarrollar una interfaz gráfica utilizando Streamlit.
- Incorporar un mecanismo de almacenamiento de información.
- Evaluar el funcionamiento mediante pruebas.

## 5. Alcance del proyecto

K.A.T.E. contempla el desarrollo de un prototipo funcional que integre una interfaz de usuario, algoritmos de búsqueda, almacenamiento de información y funcionalidades de asistencia virtual.

El desarrollo se realizará de manera incremental, priorizando las funcionalidades esenciales y considerando el tiempo disponible del equipo.
